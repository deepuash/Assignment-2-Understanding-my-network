# Computer Networking Basics

## Overview
This project covers the fundamentals of computer networking and basic network troubleshooting. The objective was to understand how devices communicate over a network and learn how to identify important network information.

## Topics Covered
- Computer Network
- Client and Server
- LAN and WAN
- Switch
- Router
- Firewall
- IP Address
- MAC Address
- Default Gateway
- DNS
- Importance of Networking in Cybersecurity

## Network Information
During the practical exercise, I identified network configuration details using Windows networking tools, including the private IPv4 address, default gateway, and DNS server.

## Commands Practiced

### ipconfig
Used to view network configuration details such as IPv4 address, IPv6 address, subnet mask, default gateway, and network adapters.

### ping
Used to test connectivity between the computer and a destination host.

Example:
ping google.com

### tracert
Used to trace the path taken by packets from the computer to a destination and identify the intermediate network hops.

Example:
tracert google.com

## Cybersecurity Relevance
Networking knowledge is important in cybersecurity because many attacks involve network communication. Understanding IP addresses, ports, protocols, traffic, and network logs helps in detecting and investigating activities such as network scanning, malware communication, and data theft.

## Key Takeaway
This hands-on exercise helped me build a foundation in computer networking and gain practical experience with basic Windows networking commands used for network identification, connectivity testing, and troubleshooting.
